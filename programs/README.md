# Protocol programs

Generated by `programs/report.py` from the test results: do not edit by hand.

Every program runs on the chip model (`sim/model/chip.py`) and is judged on the pins by reference
devices written from the protocol specifications (`test/shared/devices.py`), independent of the
emulator. For 17 protocols the pins are also read by the protocol decoders of sigrok
(`test/shared/sigrok.py`), written by the sigrok project and never shown openPIO: the test
passes only if sigrok reads the same data. Program size in instructions (of 64, one IMEM page).
